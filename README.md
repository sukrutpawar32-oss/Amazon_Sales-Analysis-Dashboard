README – Amazon Dashboard Power BI Project
📌 Project Overview

This Power BI dashboard visualizes Amazon sales and performance metrics. It helps users analyze orders, customers, product categories, revenue trends, and operational performance through interactive visuals.

🎯 Objectives

Understand overall sales performance.

Analyze product category contributions.

Track monthly/weekly revenue trends.

Study customer ordering patterns.

Identify top-performing products and regions.

Improve data-driven business decisions.

📁 File Information
